# Apresentação do projeto

Duas páginas para mostrar o rag-leis a quem não leu o código. Abra o arquivo no navegador (dois cliques); as fontes e a biblioteca de desenho vêm da internet, então sem conexão a página abre com fontes do sistema e traços retos.

| Arquivo | Para quem | O que tem |
| --- | --- | --- |
| [`rag-leis-na-empresa.html`](rag-leis-na-empresa.html) | Recrutador, gestor, alguém sem formação técnica | História desenhada em seis cenas: o problema numa central de atendimento, o risco de alucinação, a busca numa estante com os 406 artigos reais, o boletim de confiança, os experimentos e por que tudo roda local |
| [`rag-leis-por-dentro.html`](rag-leis-por-dentro.html) | Entrevista técnica | Demo com saídas reais do baseline, as sete peças do RAG, o gabarito, as métricas por tipo de pergunta, o juiz LLM, o roteiro e o plano de carreira |

Os números nas páginas são do split `dev` e foram copiados de `results/`. Quando os resultados mudarem, as páginas precisam ser atualizadas à mão.
