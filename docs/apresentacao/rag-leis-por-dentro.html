Uma pergunta sobre a lei, uma resposta com o artigo.

    Como funciona

    Prova sem consulta vira prova com consulta

    Sozinho, um LLM responde de memória e pode inventar com confiança. Com RAG, o sistema primeiro procura os artigos certos e só então o modelo responde, usando apenas o que achou. São sete peças, sempre nesta ordem. Toque em cada uma.

    O mapa de significado

    O embedding dá a cada artigo uma coordenada. Textos sobre o mesmo assunto ficam vizinhos, mesmo sem palavras em comum. A pergunta vira um ponto no mesmo mapa, e a busca traz os vizinhos mais próximos.

    Ilustração com posições inventadas. O mapa real tem 1.024 dimensões (bge-m3), não duas. O vizinho mais próximo da pergunta da loja, porém, é real: o art. 35 do CDC veio em 1º lugar, com similaridade 0,556.

    Conjunto ouro

    O gabarito foi escrito antes da busca existir

    É a mesma lógica de separar o conjunto de teste antes de treinar um modelo. Quem escreve as perguntas depois de ver o sistema funcionando escolhe, sem perceber, as que ele acerta.

    75 perguntas, cinco jeitos de quebrar o sistema

    dev · 39 · ajuste
    test · 36 · usado 1 vez

    Três regras para o gabarito valer

    1. Perguntas antes da busca. O gabarito nasceu na fase 2; a busca só na fase 3.

    2. Dev e test separados. O sistema é ajustado olhando o dev. O test só é aberto no fim, uma vez. Senão o ajuste vira overfitting no gabarito.

    3. Pergunta gerada por LLM precisa de leitura humana. As 75 foram redigidas pelo Claude e estão sendo validadas uma a uma. A validação já corrigiu q005, q009 e q011.

    Cada pergunta tem artigos_esperados (o recall é medido sobre eles) e, em 12 casos, artigos_aceitos: correlatos que também respondem. Isso evita punir a busca por trazer um artigo certo que não estava no gabarito.

    LLM como juiz

    Antes de medir, conferir a régua

    Recall e MRR saem de código puro: basta comparar ids. Já "a resposta está correta?" precisa de um leitor. O projeto usa um LLM como corretor, mas só confia nele depois de testá-lo com respostas erradas de propósito.
